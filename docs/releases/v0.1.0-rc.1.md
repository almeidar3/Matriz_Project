# Matriz 0.1.0-rc.1

**Estado:** candidata académica, não publicada.

## Incluído

- Aplicação Flask com interface, API e persistência SQLite.
- Container Docker executado através de Compose; o volume nomeado preserva a base de dados entre recriações do container.
- Healthcheck HTTP em `/api/health`.
- Workflow GitHub Actions para executar testes unitários/de integração, E2E, verificação JavaScript e build Docker.
- Instruções de setup, execução e teste no README.

## Configuração local

Requer Docker Desktop com Docker Compose. Copia `.env.example` para `.env`, substitui a chave de exemplo por uma chave aleatória local e segue os comandos Docker Compose no README. Depois de iniciar o serviço, executa `docker compose exec web flask --app app seed-demo` para criar os dados fictícios.

## Limitações

- Esta versão é apenas para a atividade académica; o servidor de desenvolvimento do Flask não é adequado para produção.
- SQLite e contas demonstrativas são locais; não há serviço externo de base de dados nem gestão de contas de produção.
- A publicação da release e da imagem não faz parte desta entrega.
- Build, healthcheck, fluxo de API e persistência Docker foram verificados localmente; a pipeline ainda não foi executada no GitHub. Os resultados estão em `docs/verification.md`.
